# EchoTrace Operator Cheat Sheet

## Open the exhibit each day
1. Open **Daily Start**.
2. Confirm the top status banner says **System ready**.
3. Run **Test Sound** and **Test Light** for each object.
4. Apply the correct operational preset for the day.
5. Print transcript labels if they changed.

## If something is wrong
- Open **Problems**.
- Read the red cards first.
- Follow the action sentence shown on each card.
- If a node is stale, wait for auto-retry or press **Reconnect**.

## Common tasks
- Rename objects: **Setup Wizard**
- Change story pack: **Content**
- Change accessibility mode: **Accessibility**
- Print transcript cards: **Transcript Cards**
- Undo the last dashboard change: top-right **Undo Last Change**

## Safe defaults
- Use **Quiet Morning** for low-stimulation openings.
- Use **School Group** when pacing needs to be faster.
- Leave **Museum Staff Mode** on unless a technician needs advanced controls.
